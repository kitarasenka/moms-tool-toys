# KeyMom

Раскладка клавиатуры в стиле Mom's Tool Toys (SwiftUI, macOS 14+). Напечатали «ghbdtn» вместо «привет» —
одно сочетание клавиш, и слово исправлено, а раскладка переключена. Ещё KeyMom показывает текущий язык
в строке меню и предупреждает о включённом Caps Lock, особенно в поле пароля. Работает из строки меню,
даже когда окно закрыто.

## Возможности

- **Исправить раскладку** — **⇧⌘ Пробел** в любом приложении (можно выбрать ⌃⇧ / ⌥⇧ / ⌃⌥⌘ Пробел).
  Если есть выделение — исправляется оно, если нет — слово перед курсором. Направление определяется само
  (латиницы больше — в русский, кириллицы — в английский), правильно набранные слова и знаки рядом с ними
  не трогаются («Привет, ujdjhb» → «Привет, говори»), числа и время тоже («10:30» остаётся). Повторное нажатие
  возвращает как было. После исправления раскладка переключается на язык текста (выключается в настройках).
  Сочетание регистрируется через Carbon `RegisterEventHotKey` (разрешений не требует); все варианты — с пробелом
  и не пересекаются с ⌃Space / ⌃⌥Space (переключение раскладки), ⌘Space (Spotlight), ⌃⌘Space (эмодзи),
  ⌥⌘Space (поиск Finder), ⇧⌘V (ClipMom).
- **Две русские раскладки** — «Русская – ПК» (точка и запятая справа внизу, ё слева от 1) и «Русская» от Apple
  (точка и запятая на Shift+7 / Shift+6, ё на клавише «\»). По умолчанию KeyMom берёт текущую или включённую;
  можно выбрать вручную. Английская — US/ABC.
- **Исправить текст** (⌘2) — окно для длинных текстов: вставили абракадабру — ниже исправленный вариант,
  «Скопировать» (⌘↩). Направление можно задать вручную. Разрешения не нужны.
- **Индикатор** — в строке меню текущая раскладка: буквы (RU / EN), флажок или значок; при смене раскладки у курсора
  на 0,8 с появляется плашка «RU» / «EN». Смена ловится уведомлением `TISNotifySelectedKeyboardInputSourceChanged`
  (`deliverImmediately`, иначе фоновому приложению оно приходит с задержкой) и подстраховочным опросом.
- **Caps Lock** — при включении плашка у курсора и «⇪» в строке меню. Если включён Caps Lock и одновременно
  безопасный ввод (`IsSecureEventInputEnabled()` — курсор в поле пароля), у курсора висит красное предупреждение
  «Пароль может не подойти». Опрос `CGEventSource.flagsState` раз в 0,3 с, без разрешений.
- **Строка меню** — раскладка, Caps Lock, последнее исправление, «Исправить раскладку», «Исправить текст…»,
  «Как пользоваться…», «Настройки…», «Завершить». По умолчанию значка в Dock нет — KeyMom живёт только в строке меню (включается в настройках)
  (`NSApp.activationPolicy = .accessory`); повторный запуск из лаунчера открывает окно.
- **Настройки** (⌘3 или ⌘,) — сочетание, переключение раскладки, русская раскладка, вид индикатора, плашки,
  предупреждение о пароле, значок в Dock, автозапуск (`SMAppService`), состояние разрешений.

## Как исправляется текст

1. **Напрямую через Accessibility** (`AXFocusedUIElement` → `AXSelectedText` / `AXValue` + `AXSelectedTextRange`):
   KeyMom читает выделение или слово перед курсором и заменяет его, затем перечитывает текст и проверяет, что замена
   действительно произошла. Буфер обмена не трогается. Так работают Заметки, TextEdit, Почта, Pages, Safari и большинство
   обычных macOS-приложений.
2. **Запасной путь через буфер обмена** — где приложение не отдаёт текст (часть браузеров и Electron-приложений:
   Telegram, Slack, VS Code): снимок буфера (все элементы и типы) → ⌘C (а если ничего не выделено — ⌥⇧← и ⌘C) →
   исправленный текст в буфер с пометками `org.nspasteboard.ConcealedType` + `TransientType` (ClipMom и другие менеджеры
   буфера его не запишут) → ⌘V → через 0,4 с прежнее содержимое возвращается (с пометкой `TransientType`, чтобы
   не считаться новым копированием). Перед этим KeyMom ждёт, пока вы отпустите ⇧⌘.

## Разрешения

- **Универсальный доступ** — нужен для исправления в других приложениях (чтение/замена текста и нажатия ⌘C/⌘V).
  Запрос появляется только при первом нажатии сочетания или при включении функции; карточка в окне объясняет, где включить:
  «Системные настройки → Конфиденциальность и безопасность → Универсальный доступ → KeyMom».
  `Scripts/build_app.sh` подписывает с постоянным требованием `designated => identifier "local.keymom"`, поэтому
  разрешение переживает пересборку (с обычной ad-hoc подписью требование — хеш сборки, и после пересборки переключатель
  горит, а доступа нет). Если KeyMom всё равно пишет «нет доступа» — сбросьте запись:
  `tccutil reset Accessibility local.keymom`, перезапустите KeyMom и включите его в списке заново.
- **Вставка из других приложений** (macOS 15.4+ / 26) — только для запасного пути через буфер. Чтобы macOS не спрашивала
  при каждом исправлении, выберите для KeyMom «Разрешить». При «Запретить» запасной путь выключается.
- Индикатор, Caps Lock и окно «Исправить текст» работают без разрешений.

## Сборка и проверка

```sh
./Scripts/build_app.sh                    # build/KeyMom.app (иконка — Resources/AppIcon.png)
swift run KeyMom --selftest               # таблицы обеих раскладок, направление, слово перед курсором,
                                          # снимок/восстановление буфера на отдельном именованном буфере, сочетания
open build/KeyMom.app --args --demo       # настройки в памяти, сочетание не регистрируется, чужие окна не меняются
open build/KeyMom.app --args --demo --section convert --hud warning   # раздел + плашка у курсора для скриншота
```

Прочие аргументы: `--section guide|convert|settings`, `--hud layout|caps|warning|success`, `--no-dock`, `--close-window`.

## Устройство

```
Sources/KeyMom/
  KeyMomApp.swift       точка входа, окно, строка меню (индикатор), повторное открытие, аргументы запуска
  AppState.swift        раскладка и Caps Lock (опрос), сочетание, исправление (AX → запасной путь через буфер)
  SelfTest.swift        `--selftest`
  Model/
    Layout.swift        таблицы клавиш US ↔ Русская – ПК / Русская (Apple), направление, перевод по словам
    InputSources.swift  TIS: текущая раскладка, включённые, выбор русской, переключение, уведомление о смене
    TextAccess.swift    Accessibility: выделение, слово перед курсором (UTF-16), замена с проверкой
    Pasteboard.swift    снимок/восстановление буфера, временная запись с пометками nspasteboard.org
    System.swift        сочетания (Carbon), Универсальный доступ, CGEvent ⌘C/⌘V/⌥⇧←, Caps Lock, автозапуск

  Views/                «Как пользоваться» (рисунок сочетания SwiftUI), «Исправить текст», настройки,

```

## Ограничения

- Исправляется последнее «слово» до пробела: «ghbdtn,» — одно слово, и запятая тоже переведётся (это клавиша «б»).
  Несколько слов — выделите их.
- Регистр не исправляется («gHBDTN» → «пРИВЕТ»), как и раскладки, кроме US/ABC и двух русских.
- В запасном пути ⌘C делает само приложение, поэтому эту копию может успеть записать менеджер буфера (ClipMom опрашивает
  буфер раз в 0,5 с); исправленный текст и возвращённое содержимое помечены и не записываются.
- В полях пароля исправление не работает (macOS не отдаёт их текст) — и это правильно.
