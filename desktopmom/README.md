# DesktopMom

Порядок на Рабочем столе и в Загрузках в стиле Mom's Tool Toys (SwiftUI, macOS 14+). Раскладывает
снимки экрана по папкам месяцев, убирает со стола остальное по типам, находит в Загрузках установщики
уже установленных приложений и давно забытые файлы. Всё сделанное записывается в журнал, откуда
любое действие можно отменить.

## Разделы

- **Рабочий стол** (⌘1). Наверху сводка: сколько объектов, сколько из них снимков экрана, сколько всё весит.
  Слева то, что лежит на столе, по группам: снимки и записи экрана, документы, картинки и фото, видео
  и музыка, установщики и программы, архивы, папки, прочее. Справа три карточки:
  - **Разложить снимки экрана** — переносит их в `~/Pictures/Снимки экрана/2026-11 ноябрь/` и т. д.
    Перед действием показано, сколько снимков попадёт в какой месяц. Папку можно сменить: годится
    любая внутри домашней, кроме самого Рабочего стола. Снимок узнаётся по метке, которую ставит
    macOS (`com.apple.metadata:kMDItemIsScreenCapture` в xattr или в Spotlight), и по имени:
    «Снимок экрана …», «Запись экрана …», «Screenshot …», «Screen Recording …». По имени узнаются
    только картинки и видео, поэтому «Screenshot ideas.docx» в снимки не попадёт.
  - **Новые снимки экрана** — показывает, куда macOS сохраняет снимки сейчас, и одной кнопкой меняет
    это место на папку снимков (`defaults write com.apple.screencapture location`). Это та же
    настройка, что «⇧⌘5 → Параметры → Сохранить в». Кнопка «Вернуть на Рабочий стол» удаляет ключ.
  - **Остальное** — по галочкам групп (по умолчанию ни одна не отмечена) переносит выбранное в
    `~/Documents/Разобрать/<Документы|Картинки|…>/`.
- **Загрузки** (⌘2). Фильтры: Всё / Установщики / Уже установлено / Давно / Крупные (от 100 МБ).
  - «Уже установлено» — это догадка по имени. `zoomusInstallerFull.pkg` превращается в `zoomus`,
    `Telegram-macOS-11.2.dmg` — в `telegram`, и полученное слово сравнивается с приложениями в
    `/Applications`, `/Applications/Utilities` и `~/Applications`. Подсказка у метки показывает,
    с каким приложением совпало имя.
  - «Давно» — файл не открывали, не меняли и не скачивали дольше выбранного срока
    (месяц, 3 месяца, полгода или год; по умолчанию 3 месяца).
  - «Отметить предложенное» отмечает установщики уже установленных приложений и установщики, которые
    давно не открывали. «В Корзину…» спрашивает подтверждение.
- **Журнал** (⌘3) — каждое перемещение и перенос в Корзину: имя, откуда, куда, когда. «Вернуть»
  кладёт файл обратно, если он всё ещё на новом месте, а старое место свободно (работает и для Корзины).
  Кнопка с лупой показывает файл в Finder или в Корзине.

## Безопасность

- Удаления нет совсем: снимки и «остальное» только перемещаются, из Загрузок выбранное переносится
  в Корзину (`FileManager.trashItem`) после подтверждения.
- Обрабатывается только верхний уровень своей папки (Рабочего стола или Загрузок), в подпапки
  DesktopMom не заходит. Перед каждой операцией проверяется, что папка, где лежит объект, — после
  раскрытия ссылок и `..` через `realpath` — ровно Рабочий стол или Загрузки. Поэтому ни
  `Desktop/../файл`, ни файл за ссылкой-папкой, ведущей наружу, не пройдут.
- Ссылка переносится как ссылка, то, на что она указывает, не трогается. `.app` и другие пакеты
  считаются одним объектом. Скрытые файлы и `.localized` не показываются и не трогаются.
- Папка назначения должна лежать внутри домашней папки и не внутри самого переносимого объекта.
  Перезаписи нет: при совпадении имени файл получает имя «… 2», «… 3».
- Журнал хранится в `~/Library/Application Support/DesktopMom/log.json` (папка 0700, файл 0600),
  в нём не больше 3000 записей. В сеть ничего не отправляется.

## Доступ к папкам

Рабочий стол, Загрузки и Документы macOS охраняет, поэтому при первом открытии раздела она один раз
спросит разрешение. Это нормально. Если доступ запрещён, DesktopMom покажет карточку с кнопкой
«Открыть настройки» («Конфиденциальность и безопасность → Файлы и папки»). Сканируется только
открытый раздел. После пересборки ad-hoc подпись меняется, и разрешение, возможно, придётся выдать заново.

## Сборка и проверка

```sh
./Scripts/build_app.sh                  # build/DesktopMom.app (иконка — Resources/AppIcon.png)
swift run DesktopMom --selftest         # песочница: снимки (имя + xattr), месяцы, уникальные имена, отказы
                                        # (../, ссылка наружу, вне дома, в себя), «уже установлено», возраст,
                                        # Корзина-папка, журнал 0600 и «Вернуть»
open build/DesktopMom.app --args --demo                                    # выдуманные файлы в памяти
open build/DesktopMom.app --args --demo --pane downloads --select-suggested
open build/DesktopMom.app --args --demo --organize --pane journal
```

Прочие аргументы: `--pane desktop|downloads|journal` и `--filter all|installers|installed|old|large`.
В `--demo` настоящие папки не читаются, а настройка снимков экрана не меняется.

## Устройство

```
Sources/DesktopMom/
  DesktopMomApp.swift   точка входа, меню (⌘1…⌘3, ⌘R), аргументы запуска
  AppState.swift        состояние разделов, действия, баннер с итогом
  Demo.swift            выдуманные файлы для --demo
  SelfTest.swift        --selftest на временной песочнице
  Model/
    Core.swift          корни, realpath-проверки путей, Корзина, defaults для снимков экрана, формат
    Files.swift         группы, распознавание снимков, обход верхнего уровня, «уже установлено»
    Organizer.swift     папки месяцев, уникальные имена, перенос и Корзина с проверками, журнал и «Вернуть»
  Views/                Рабочий стол, Загрузки, Журнал, общие компоненты (fillAvailable — см. Components.swift)
```

## Языки

Русский, английский, китайский (упрощённый), немецкий, французский и арабский.
macOS выбирает язык автоматически. Для отдельного приложения его можно изменить в «Системные настройки → Основные → Язык и регион».
