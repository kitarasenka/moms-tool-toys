# DiskMom

Всё про диски в стиле Mom's Tool Toys (SwiftUI, macOS 14+): что занимает место, одинаковые файлы
и подключённые диски. По возможностям ориентир — Space Lens из CleanMyMac и DaisyDisk.

## Разделы

- **Карта диска** (⌘1) — выберите, что считать: домашняя папка, Macintosh HD или любая папка.
  Сканирование идёт в фоне (счётчик файлов, текущая папка, «Остановить»), потом — круговая диаграмма
  на три кольца: сектор тем шире, чем больше папка, цвет — по папке первого уровня, мелочь собрана
  в «Остальное». Щелчок по сектору — заглянуть внутрь, по середине — на уровень выше (⌘↑), сверху —
  «хлебные крошки». Справа — содержимое по размеру с полосками. Выбранное можно показать в Finder
  или перенести в Корзину (с подтверждением; размеры родителей пересчитываются сразу).
  - Считается «размер на диске», как в Finder; ссылки не разыменовываются; другие тома внутри папки
    не считаются (у `/` — без `/System/Volumes` и `/Volumes`, данные пользователя — через firmlink-и).
  - Пакеты (`.app`, `.photoslibrary` и т. п.) — один объект с полным размером.
  - Файлы меньше 256 КБ в больших папках показываются одной строкой «Мелкие файлы».
  - Нечитаемые папки только считаются («Не прочитано папок: N»), сканирование не прерывают.
  - Без полного доступа к диску контейнеры других приложений (`~/Library/Containers`,
    `Group Containers`) не открываются — иначе macOS засыпает запросами; облачные диски
    (`~/Library/CloudStorage`) не сканируются никогда.
- **Дубликаты** (⌘2) — по умолчанию Загрузки, Документы, Рабочий стол, Изображения (папки можно
  менять), файлы от 1 МБ. Поиск: одинаковый размер → SHA-256 первых и последних 64 КБ → полный SHA-256.
  Пакеты (медиатека «Фото» и др.), скрытые файлы, ссылки, `~/Library` пропускаются; жёсткие ссылки на
  один файл дубликатами не считаются. Группы с миниатюрой, папками и датами; автовыбор «оставить
  самый новый / самый старый / копии в папке…». Отметить все копии группы нельзя — одна остаётся всегда
  (и ещё раз проверяется перед переносом). Перед переносом в Корзину проверяется, что файл не изменился.
- **Диски** (⌘3) — все подключённые тома: встроенные, внешние, сетевые, образы дисков. Заполненность,
  свободное место (у загрузочного — с учётом того, что macOS может освободить), формат, устройство,
  SSD/HDD, состояние S.M.A.R.T. (`diskutil info -plist`, без пароля). «Открыть в Finder»,
  «Карта диска», «Извлечь» для внешних, сетевых и образов. Список обновляется сам при
  подключении и отключении дисков.

## Безопасность

- Удаление — только перенос в Корзину (`FileManager.trashItem`), только выбранного, только после
  подтверждения. На карте — строго внутри сканированной папки, сам корень не трогается.
- `--selftest` проверяет поиск, автовыбор, защиту «не все копии» и перенос на временной песочнице
  (вместо Корзины — папка песочницы, настоящая Корзина не засоряется).

## Доступ к папкам

При первом сканировании Рабочего стола, Документов, Загрузок, внешних и сетевых дисков macOS
спросит разрешение — это нормально. С «Полным доступом к диску» карта посчитает и закрытые папки
(Почта, Сообщения, контейнеры приложений). После пересборки ad-hoc подпись меняется — разрешения,
возможно, придётся выдать заново.

## Сборка и проверка

```sh
./Scripts/build_app.sh                         # build/DiskMom.app (иконка — Resources/AppIcon.png)
swift run DiskMom --scan /Applications --fm    # 10 самых больших объектов, время (+ сверка с FileManager)
swift run DiskMom --dupes ~/Pictures --min 1000000   # группы дубликатов, ничего не удаляя
swift run DiskMom --volumes                    # подключённые тома
swift run DiskMom --selftest                   # песочница: дубликаты, защита копий, Корзина, дерево размеров
open build/DiskMom.app --args --section map --path /Applications --autoscan [--drill 1]
open build/DiskMom.app --args --section dupes --folder ~/Pictures --min 100000 --autoscan
open build/DiskMom.app --args --section disks
```

## Устройство

```
Sources/DiskMom/
  DiskMomApp.swift      точка входа, меню (⌘1…⌘3), аргументы запуска
  SelfTest.swift        консольные режимы --scan, --dupes, --volumes, --selftest
  AppState.swift        состояние разделов (MapStore, DupesStore, VolumesStore)
  Model/
    Core.swift          формат, пути, полный доступ к диску, Корзина, запуск команд
    SizeTree.swift      дерево размеров и сканер на getattrlistbulk (параллельно по папкам)
    Duplicates.swift    поиск дубликатов, правила автовыбора, защита копий, перенос в Корзину
    Volumes.swift       тома, diskutil, извлечение
  Views/                экраны, солнечная диаграмма (Sunburst.swift), общие компоненты
                        (fillAvailable — см. комментарий в Components.swift)
```

Скорость: `/Applications` (≈790 тыс. файлов) — около 4 с против ≈19 с через FileManager, размеры совпадают.
