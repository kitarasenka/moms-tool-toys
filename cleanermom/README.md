# CleanerMom

Уборка Mac в стиле Mom's Tool Toys (SwiftUI, macOS 14+). По возможностям ориентир — CleanMyMac:
мусор одной кнопкой, крупные файлы, удаление приложений со следами, обслуживание.

## Разделы

- **Умная очистка** (⌘1) — «Сканировать» → карточки категорий с размерами → «Очистить».
- **Мусор** (⌘2) — те же находки подробно: категория слева, объекты справа, галочка у каждого.
  - Система: кэши приложений (`~/Library/Caches`), журналы и отчёты о сбоях (`~/Library/Logs`),
    временные файлы старше недели (`$TMPDIR`), Корзина.
  - Браузеры: кэш Safari, Chrome, Firefox, Яндекс, Brave, Edge, Arc, Opera, Vivaldi (история, пароли и вход на сайты не трогаются).
  - Разработка: Xcode (DerivedData, DeviceSupport, кэш симуляторов); кэши npm, Yarn, Homebrew, pip, Gradle, Cargo и др. (по умолчанию выключены).
  - Файлы: вложения Почты, прошивки iPhone/iPad, установщики `.dmg/.pkg` в Загрузках и резервные копии устройств (последние два — выключены и только в Корзину).
- **Крупные файлы** (⌘3) — файлы от 20 МБ в домашней папке; фильтр по размеру и «не менялись полгода/год», поиск; выбранное — в Корзину.
- **Деинсталлятор** (⌘4) — сторонние приложения из `/Applications` и `~/Applications` с размером и датой запуска; удаляет приложение вместе с настройками, кэшем, контейнером и т. п. из `~/Library` (галочки можно снять). Приложения Apple не показываются.
- **Обслуживание** (⌘5) — сброс кэша DNS, освобождение памяти (`purge`), переиндексация Spotlight (нужен пароль), перестройка Launch Services, сброс Quick Look.

## Безопасность

- Кэши, журналы, временные файлы, Корзина — удаляются сразу (приложения создадут нужное заново).
  Файлы пользователя (установщики, резервные копии, крупные файлы, приложения) — **в Корзину**.
- Каждый найденный объект помнит папку-корень; удаляется только то, что лежит строго внутри неё,
  а корень — внутри домашней или временной папки (`Cleaner.isSafe`, проверка — `--selftest-clean`).
- Кэш запущенного приложения и браузера не отмечается — можно отметить вручную.
- Не трогаем кэши iCloud, «Локатора», связки ключей, фоновых загрузок (`Catalog.protectedCaches`).

## Полный доступ к диску

Без него закрыты Корзина, Почта, резервные копии и контейнеры других приложений. CleanerMom в них
не стучится (иначе macOS засыпает запросами «доступ к данным других приложений») и показывает плашку
со ссылкой на настройки. Корзину без доступа можно очистить через Finder. После пересборки ad-hoc
подпись меняется — разрешение, возможно, придётся выдать заново.

## Сборка и проверка

```sh
./Scripts/build_app.sh                     # build/CleanerMom.app (иконка — Resources/AppIcon.png)
swift run CleanerMom --scan                # найти мусор и вывести сводку, ничего не удаляя
swift run CleanerMom --selftest-clean      # удаление на временной песочнице + проверка защиты
swift run CleanerMom --apps                # приложения и найденные следы (без удаления)
open build/CleanerMom.app --args --section junk --autoscan   # раздел + сразу поиск (smart|junk|large|uninstaller|maintenance)
```

## Устройство

```
Sources/CleanerMom/
  CleanerMomApp.swift   точка входа, меню, аргументы запуска, консольные проверки
  AppState.swift        состояние разделов (JunkStore, LargeFilesStore, UninstallerStore, MaintenanceStore)
  Model/
    Core.swift          размер на диске, свободное место, пути, полный доступ к диску, запуск команд
    Junk.swift          каталог категорий мусора, сканирование, безопасное удаление
    Apps.swift          список приложений, поиск следов в ~/Library, удаление в Корзину
    LargeFiles.swift    поиск крупных файлов
    Maintenance.swift   процедуры обслуживания
  Views/                экраны и общие компоненты (fillAvailable — см. комментарий в Components.swift)
```

## Языки

Русский, английский, китайский (упрощённый), немецкий, французский и арабский.
macOS выбирает язык автоматически. Для отдельного приложения его можно изменить в «Системные настройки → Основные → Язык и регион».
