# ClipMom

История буфера обмена в стиле Mom's Tool Toys (SwiftUI, macOS 14+). Всё, что скопировано, —
текст, ссылки, картинки, файлы из Finder — можно найти и вернуть в буфер. Работает в строке меню,
даже когда окно закрыто.

## Возможности

- **Запись** — каждые 0,5 с ClipMom сверяет только счётчик изменений буфера (`changeCount`, без чтения
  содержимого) и читает буфер лишь после нового копирования. Запоминает, из какого приложения скопировано.
  Повтор того же содержимого не дублируется — запись поднимается наверх.
- **Не записывает** пароли и служебное: типы `org.nspasteboard.ConcealedType`, `TransientType`,
  `AutoGeneratedType`, `com.agilebits.onepassword`; всё из исключённых приложений (по умолчанию —
  Связка ключей, Пароли, 1Password, Bitwarden, KeePassXC; список меняется в настройках) — из них ClipMom
  даже не читает. Текст больше 1 МБ и картинки больше 20 МБ пропускаются. Есть пауза и «Не записывать 5 минут».
- **Окно** (фильтры: Всё / Текст / Ссылки / Картинки / Файлы / Закреплённые, поиск) — список с миниатюрами,
  иконкой приложения и временем; справа просмотр и действия: **Скопировать** (⌘↩, двойной щелчок),
  **Закрепить**, **Удалить** (⌫). Возвращённое в буфер ClipMom помечает и повторно не записывает.
- **Быстрая панель ⇧⌘V** из любого приложения — у курсора, поиск сразу в фокусе; ↑/↓, ↩ — скопировать,
  ⌘1…⌘9 — выбрать запись, Esc — закрыть. Сочетание регистрируется через Carbon, разрешений не требует.
  Внимание: в части приложений ⇧⌘V — «Вставить и согласовать стиль»; пока ClipMom запущен, его перехватывает панель
  (выключается в настройках). Как ею пользоваться, показывает картинка с инструкцией: справа в окне, пока
  ничего не выбрано, в меню «Справка → Как вызвать ClipMom», в строке меню и в настройках.
- **«Вставлять сразу»** (выключено по умолчанию) — после выбора в панели ClipMom нажимает ⌘V в приложении,
  где вы были. Для этого нужен «Универсальный доступ»; запрос появляется только при включении функции.
- **Строка меню** — 10 последних записей (щелчок — скопировать), быстрая панель, справка, пауза, «Открыть ClipMom»,
  «Настройки…», «Завершить». Если выключить «Показывать значок в Dock», ClipMom живёт только в строке меню
  (`NSApp.activationPolicy = .accessory`); повторный запуск из лаунчера по-прежнему открывает окно.
- **Настройки** (⌘,) — сколько хранить (по умолчанию 300 записей и 30 дней; закреплённые не истекают),
  исключённые приложения, ⇧⌘V, «Вставлять сразу», значок в Dock, автозапуск при входе (`SMAppService`), «Очистить историю…».

## Доступ к буферу обмена (macOS 15.4+ / 26)

Apple ввела запрос «приложение хочет вставить из другого приложения» при программном чтении общего буфера.
Пользователь выбирает поведение в «Системные настройки → Конфиденциальность и безопасность → Вставка из других
приложений»: Спрашивать / Разрешить / Запретить. ClipMom проверяет `NSPasteboard.accessBehavior`:

- «Разрешить» или запрос ещё не показывался — записывает как обычно (во втором случае macOS может один раз спросить);
- «Спрашивать» — сам не читает буфер, чтобы не спрашивать при каждом копировании, и показывает карточку;
- «Запретить» — не читает, показывает карточку с кнопкой «Открыть настройки».

Чтобы всё работало без вопросов, выберите для ClipMom **«Разрешить»**. `Scripts/build_app.sh` подписывает
с постоянным требованием `designated => identifier "local.clipmom"`, поэтому разрешения (и «Универсальный доступ» для
«Вставлять сразу») переживают пересборку. Если переключатель включён, а ClipMom пишет, что доступа нет, — сбросьте запись
(`tccutil reset Accessibility local.clipmom`), перезапустите ClipMom и включите заново.

## Хранение

`~/Library/Application Support/ClipMom/` — `history.json` и `images/` (PNG и миниатюры). Папки 0700, файлы 0600.
В сеть ничего не отправляется.

## Сборка и проверка

```sh
./Scripts/build_app.sh                  # build/ClipMom.app (иконка — Resources/AppIcon.png)
swift run ClipMom --selftest            # запись на отдельном буфере, пропуск паролей, дедупликация, сроки, права файлов
open build/ClipMom.app --args --demo    # образцы записей в памяти: история и буфер обмена не трогаются
open build/ClipMom.app --args --demo --panel --select 2   # + быстрая панель, выделить третью запись
```

Прочие аргументы: `--settings`, `--guide` (справка по ⇧⌘V), `--no-dock` (только строка меню, в демо не сохраняется),
`--filter link` (all|text|link|image|files|pinned), `--close-window`.

## Устройство

```
Sources/ClipMom/
  ClipMomApp.swift      точка входа, окно, строка меню, повторное открытие, аргументы запуска
  AppState.swift        запись буфера по таймеру, пауза, действия, сохранение
  SelfTest.swift        `--selftest` и образцы для `--demo`
  Model/
    Clip.swift          запись истории, фильтры, распознавание ссылок, лимиты
    Pasteboard.swift    чтение/запись буфера, пропуск скрытых типов, changeCount, accessBehavior
    Store.swift         history.json + images/, история (дедупликация, закрепление, сроки)
    Preferences.swift   настройки и исключённые приложения
    System.swift        ⇧⌘V (Carbon), «Вставлять сразу» (AX + CGEvent), автозапуск, иконки
  Views/                окно, просмотр, настройки, быстрая панель (fillAvailable — см. Components.swift)
    HotkeyGuide.swift   справка «Как вызвать ClipMom» с рисунком панели (SwiftUI, без картинок-файлов)
```

## Языки

Русский, английский, китайский (упрощённый), немецкий, французский и арабский.
macOS выбирает язык автоматически. Для отдельного приложения его можно изменить в «Системные настройки → Основные → Язык и регион».
