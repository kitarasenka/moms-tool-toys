# PerfMon

Нативный монитор производительности для macOS (SwiftUI, macOS 14+).

## Возможности

- **Обзор** — загрузка ЦП (система/пользователь, по ядрам), память (приложения, зарезервировано, сжато, кэш, своп, давление), сеть и диск с графиками истории, топ процессов по ЦП, памяти и сетевому трафику.
- **Процессы** — сортируемая таблица: % ЦП, время ЦП, память (phys_footprint, как в Мониторинге системы), потоки, сеть (получено/отправлено в секунду), чтение/запись диска, PID, пользователь, путь. Столбцы скрываются и показываются правым кликом по заголовку. Фильтры: все / мои / приложения / системные, поиск по имени, PID, пути, пользователю.
- **Дерево процессов** — иерархия от `kernel_task` с суммами ЦП, памяти и сетевого трафика по поддеревьям (видно, например, сколько качает браузер со всеми helper-процессами).
- **Инспектор процесса**
  - *Цепочка* — путь `kernel_task → launchd → … → процесс → исполняемый файл`, «ответственное приложение» (от чьего имени macOS считает процесс запущенным), дочерние процессы. Любой узел кликабелен.
  - *Сводка* — графики ЦП/памяти/сети процесса, диск, время запуска, родитель, подпись кода (Apple / Developer ID / ad-hoc / без подписи, Team ID, Hardened Runtime), информация о пакете приложения.
  - *Файлы* — открытые файлы, папки, устройства, TCP/UDP-соединения (адреса, порты, состояние), Unix-сокеты, каналы.
  - *Модули* — загруженные библиотеки, фреймворки, плагины, шрифты и другие отображённые в память файлы.
  - *Запуск* — аргументы командной строки, рабочая папка, переменные окружения.
- **История** (⌘6) — нагрузка за любой из последних 30 дней: графики ЦП (среднее и пик), памяти, сети и диска по времени суток; наведение на график показывает, что происходило в эти 5 минут и какие процессы нагружали систему; сводка дня (средняя и пиковая нагрузка, трафик, объём диска, сколько времени записано) и таблица «кто нагружал систему за день» (время ЦП, пик памяти, трафик; helper-процессы суммируются в своё приложение). Данные пишутся раз в минуту в `~/Library/Application Support/PerfMon/History/` (~1 МБ в день), пока PerfMon запущен; промежутки без записи видны как разрывы на графике. Окно можно закрыть — PerfMon продолжит работать и записывать историю из строки меню (там же текущая нагрузка и «Завершить»). Чтобы история была за весь день, добавьте PerfMon в «Автозагрузку → Открывать при входе».
- **Автозагрузка** (⌘4)
  - *Фоновые агенты и службы* — всё из `~/Library/LaunchAgents`, `/Library/LaunchAgents` и `/Library/LaunchDaemons`: когда запускается (при входе, при загрузке системы, постоянно, по расписанию), работает ли сейчас (с PID и переходом к процессу), кто разработчик (по подписи кода), «осиротевшие» службы, чья программа удалена. Переключатель выключает автозапуск так, что он не вернётся после перезагрузки (`launchctl disable` + остановка службы), и включает обратно. Агенты пользователя можно удалить (plist уходит в Корзину). Для системных служб нужен пароль администратора.
  - *Открывать при входе* — список приложений «Открывать при входе» из Системных настроек: добавить (+), убрать (−), скрывать окна при запуске. Работает через System Events — macOS один раз попросит разрешение.
- **Безопасность** (⌘5) — эвристическая оценка риска каждого процесса с объяснением причин. Это не антивирус: сигнатур вредоносов нет, оцениваются типичные признаки.

  | Признак | Вес |
  |---|---|
  | Подпись стала недействительной во время работы (статус из ядра, `csops`) | 4 |
  | Исполняемый файл удалён, а процесс работает | 4 |
  | Маскировка под системный процесс (`launchd`, `com.apple.*`…) без подписи Apple | 4 |
  | Внедрение библиотек через `DYLD_INSERT_LIBRARIES` | 4 |
  | Запуск из `/tmp`, `/Users/Shared`, «Загрузок», Корзины | 3 |
  | Нет подписи | 3 |
  | Скачан из интернета (карантин) без сертификата | 2 |
  | Офис / браузер / мессенджер запустил shell, `curl`, `osascript`… | 2 |
  | Скрытая папка без сертификата | 2 |
  | Закреплён в автозагрузке без сертификата | 2 |
  | Ad-hoc подпись, подключённый отладчик, сеть или высокий ЦП без сертификата | 1 |

  Сумма ≥ 4 — «Подозрительно», 2–3 — «Обратите внимание», 1 — «Замечание». Ложные срабатывания (Homebrew, свои сборки) снимаются через «Доверять» — список хранится между запусками. В инспекторе кнопка «Проверить подлинность» сверяет хеши всех файлов с подписью и проверяет нотаризацию Apple / происхождение из Mac App Store.
- **Управление** — завершить (приложениям сначала отправляется штатный запрос «Завершить»), принудительно (SIGKILL), приостановить/продолжить (SIGSTOP/SIGCONT), завершить вместе со всеми потомками. Для процессов других пользователей — повтор с паролем администратора. `kernel_task` и `launchd` защищены от завершения.

## Сборка и запуск

```sh
./Scripts/build_app.sh      # соберёт build/PerfMon.app (release, ad-hoc подпись, иконка)
open build/PerfMon.app
```

Для разработки: `swift run PerfMon`. Проверка сбора данных без UI: `swift run PerfMon --selftest`.
`swift run PerfMon --selftest-launchd` — проверка включения/выключения автозапуска на временном агенте (создаётся и удаляется сам).

Открыть сразу на нужном процессе:

```sh
open build/PerfMon.app --args --pid 1234 --tab chain     # summary | chain | files | modules | launch
open build/PerfMon.app --args --section tree             # overview | processes | tree | history | startup | security
```

## Горячие клавиши

| Клавиши | Действие |
|---|---|
| ⌘1 … ⌘6 | Обзор / Процессы / Дерево / Автозагрузка / Безопасность / История |
| ⌘I | Показать/скрыть инспектор |
| ⌘L | Цепочка запуска выбранного процесса |
| ⇧⌘T | Показать процесс в дереве |
| ⇧⌘R | Показать исполняемый файл в Finder |
| ⌥⌘Q / ⇧⌥⌘Q | Завершить / завершить принудительно |
| ⌘R | Обновить сейчас |
| ⇧⌘P | Пауза обновления |

Двойной клик по строке в таблице открывает цепочку запуска, в дереве — сворачивает/разворачивает узел.

## Ограничения macOS

Без root macOS отдаёт подробную статистику только по процессам текущего пользователя. Для системных процессов (помечены 🔒):

- ЦП и память берутся из `/bin/ps` (setuid-утилита), потоки и диск недоступны;
- открытые файлы и модули можно получить кнопкой «Показать с паролем администратора» (через `lsof` с повышенными правами);
- завершение запросит пароль администратора.

Сетевой трафик по процессам берётся из системного `nettop` (публичного API для этого нет): PerfMon держит один его экземпляр запущенным в фоне (~1% ЦП), поэтому сеть видна и для системных процессов. `nettop` считает байты только по открытым соединениям, поэтому основная метрика — скорость, а «всего» относится к текущим соединениям.

Системные библиотеки macOS загружаются одним блоком из общего кэша dyld, поэтому во вкладке «Модули» по отдельности видны только сторонние библиотеки и фреймворки приложения.

## Структура

```
Sources/PerfMon/
  PerfMonApp.swift          точка входа, меню, аргументы запуска, --selftest
  AppState.swift            состояние UI: выбор, фильтры, дерево, действия над процессами
  Model/
    ProcessSampler.swift    список процессов: sysctl KERN_PROC_ALL, proc_pid_rusage, ps
    SystemSampler.swift     ЦП по ядрам, память, своп, сеть (NET_RT_IFLIST2), диск (IOKit)
    NetworkMonitor.swift    трафик по процессам: потоковый nettop через псевдотерминал
    ProcessDetails.swift    аргументы, файлы, сокеты, модули, подпись кода, lsof для root
    StartupItems.swift      автозагрузка: сканирование launchd-служб, enable/disable, объекты входа
    StartupStore.swift      состояние раздела «Автозагрузка»
    History.swift           запись истории (раз в минуту, JSONL), суточные итоги по приложениям, чтение
    SecurityAnalyzer.swift  эвристики риска, статус подписи из ядра (csops), проверка нотаризации
    ProcessControl.swift    сигналы, завершение приложений, запуск от администратора
    Monitor.swift           цикл опроса, история для графиков, связи родитель/потомки
  Views/                    SwiftUI-экраны и компоненты
Scripts/
  build_app.sh              сборка .app (иконка — Resources/AppIcon.png)
```
