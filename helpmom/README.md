# HelpMom

«Позвать на помощь» в стиле Mom's Tool Toys (SwiftUI, macOS 14+). Для мамы — понятный отчёт о Mac и
звонок помощнику одной кнопкой; для помощника — всё, что нужно знать о компьютере, в одном сообщении.

## Разделы

- **Отчёт о Mac** (⌘1) — «светофор» сверху простыми словами: «Всё в порядке» / «Есть на что посмотреть» /
  «Нужна помощь» и что с этим делать. Проверяет место на диске (< 25 ГБ или < 10 % — жёлтый, < 10 ГБ — красный),
  сколько дней без перезагрузки (≥ 7 — жёлтый, ≥ 30 — красный), давление памяти, износ батареи, есть ли интернет,
  паники ядра, частые вылеты одного приложения (≥ 3 за неделю), ожидающие обновления. Ниже плитки: модель
  («MacBook Pro (16-inch, 2021)»), чип, память, версия macOS, время работы, диск, память, батарея, сеть; топ-5
  приложений по ЦП (помощники складываются в своё приложение) и сбои за 7 дней. Кнопки: **Скопировать отчёт**
  (⇧⌘C, простой текст для мессенджера), **Сохранить на Рабочий стол** (.txt), **Отправить…** (меню «Поделиться»),
  **Обновить** (⌘R). Серийный номер попадает в отчёт только с галочкой. Внизу — предпросмотр текста.
- **Позвать на помощь** (⌘2) — помощники (имя, телефон, e-mail Apple ID, Telegram). На каждого крупные кнопки:
  видеозвонок и аудиозвонок FaceTime (`facetime://`, `facetime-audio://`), «Написать» (Сообщения с готовым текстом
  через `NSSharingService.composeMessage`), Telegram (`tg://resolve`, без приложения — `https://t.me/`),
  «Отправить отчёт» (Сообщения → Почта → Telegram с отчётом в буфере обмена). Блок «Показать экран помощнику» —
  шаги для общего экрана в FaceTime и кнопки FaceTime / «Общий экран» / настройки общего доступа.
- **Частые проблемы** (⌘3) — шпаргалки: не работает интернет, Mac тормозит, мало места, окна «ваш Mac заражён!»,
  пишет не теми буквами, приложение зависло (своё окно принудительного завершения с подтверждением), снимок
  экрана, перезагрузка (системное окно «Перезагрузить?» через `loginwindow`). У карточек кнопки «Открыть
  WifiMom / PerfMom / CleanerMom / DiskMom / DesktopMom / SafetyMom / KeyMom» — серые, если инструмент не установлен
  (ищется по bundle id).

## Откуда данные

Всё локально и быстро (≈ 1 с), без запросов разрешений TCC — Рабочий стол, Документы и Загрузки не читаются
(Рабочий стол — только при «Сохранить на Рабочий стол»).

- Модель: `IODeviceTree:/product` → `product-name` (Apple silicon), на Intel — кэш «Информации о системе»
  (`~/Library/Preferences/com.apple.SystemProfiler.plist`); чип, память, сборка, время загрузки, своп,
  давление памяти — `sysctl`; серийный номер — `IOPlatformExpertDevice`.
- Диск — `volumeAvailableCapacityForImportantUsage` для `/` (как в Finder).
- Батарея — IOPowerSources и `AppleSmartBattery` (здоровье = NominalChargeCapacity / DesignCapacity, циклы).
- Сеть — `NWPathMonitor` (тип подключения), адрес — `getifaddrs`; интернет — один `ping` до 1.1.1.1. Это
  единственное обращение к сети; SSID не читается (для него нужна геолокация).
- Процессы — `ps -Ao pcpu=,rss=,comm=`.
- Сбои — **только имена файлов** в `~/Library/Logs/DiagnosticReports` и `/Library/Logs/DiagnosticReports`
  (+ `Retired`): `Safari-2026-11-20-101010.ips` → сбой Safari, `JetsamEvent-…` → нехватка памяти,
  `panic-…` → перезагрузка из-за сбоя; `.diag`, `ExcUserFault`, скрытые файлы пропускаются. Содержимое не читается.
- Обновления — список, который macOS сохраняет после фоновой проверки (`/Library/Preferences/com.apple.SoftwareUpdate.plist`,
  `RecommendedUpdates`), без обращения к серверам Apple.

## Хранение

`~/Library/Application Support/HelpMom/helpers.json` — список помощников (папка 0700, файл 0600). Создаётся при
первом добавлении. Отчёт нигде не хранится и никуда не отправляется сам.

## Сборка и проверка

```sh
./Scripts/build_app.sh                   # build/HelpMom.app (иконка — Resources/AppIcon.png)
swift run HelpMom --selftest             # отчёт и «светофор», разбор имён сбоев, ps, ссылки, хранение (временная папка)
swift run HelpMom --report               # собрать отчёт на этом Mac и напечатать (ничего не сохраняется)
open build/HelpMom.app --args --demo     # выдуманный Mac и помощники в памяти — для скриншотов
open build/HelpMom.app --args --demo --section 2 --edit   # раздел «Позвать на помощь» + форма нового помощника
```

Прочие аргументы: `--section N` (1…3), `--serial` (с серийным номером).

## Устройство

```
Sources/HelpMom/
  HelpMomApp.swift      точка входа, окно, меню (⌘1…⌘3, ⌘R, ⇧⌘C), --selftest / --report, аргументы запуска
  AppState.swift        разделы, сбор отчёта, копирование/сохранение, помощники, FaceTime/Сообщения/Telegram, завершение приложений
  SelfTest.swift        `--selftest` и демо-данные
  Model/
    Report.swift        данные отчёта, «светофор» (findings), группировка сбоев, текст для мессенджера
    Collector.swift     сбор на этом Mac: sysctl, IOKit, NWPathMonitor, ps, имена отчётов о сбоях, обновления
    Helpers.swift       помощник, нормализация телефона/e-mail/Telegram, ссылки, helpers.json
    Core.swift          формат («111,9 ГБ»), запуск программ, sysctl, системные настройки, соседние инструменты
  Views/                отчёт, помощники и форма, частые проблемы (fillAvailable — см. Components.swift)
```
