# BatteryMom

Батарея Mac и беспроводных устройств в стиле Mom's Tool Toys (SwiftUI, macOS 14+). По возможностям
ориентир — coconutBattery и AlDente (только просмотр): здоровье и циклы батареи, история заряда,
кто тратит энергию, заряд мышей, клавиатур и наушников. Работает и на Mac без батареи (iMac, Mac mini):
тогда показывает «У этого Mac нет встроенной батареи», а разделы «Устройства» и «Расход приложений» доступны.

## Разделы

- **Батарея** (⌘1) — большое кольцо заряда; заряжается / заряжен / на паузе / от батареи, время до полного
  или до разряда; здоровье (текущая полная ёмкость к заводской, мА·ч) с вердиктом, состояние по мнению macOS
  («Нормальное» / «Рекомендуется обслуживание»), циклы из расчётных 1000, температура, напряжение, ток,
  мощность заряда/разряда, потребление всего Mac (Apple silicon), адаптер (название, ватты), дата изготовления
  (только Intel). Советы и кнопка «Открыть настройки „Аккумулятор“» (предел зарядки, оптимизированная зарядка).
- **История** (⌘2) — графики заряда и мощности за 24 часа / 7 дней (Swift Charts), пропуски там, где
  записей не было; итоги по дням: время от батареи, израсходовано %, диапазон заряда, прирост циклов.
- **Расход приложений** (⌘3) — топ-15 по «энергопотреблению» (оценка macOS, как в Мониторинге системы,
  не ватты). Helper-процессы складываются в своё приложение (по внешнему `.app` в пути). Автообновление
  раз в 30 с, пока раздел открыт.
- **Устройства** (⌘4) — заряд Bluetooth-устройств: Magic Mouse / Keyboard / Trackpad, AirPods (левый,
  правый, футляр), другие наушники; отключённые — с последним известным зарядом.
- **Строка меню** — значок батареи и процент; в меню — заряд, время, здоровье, потребление, устройства,
  «Открыть BatteryMom», «Завершить BatteryMom». Закрытое окно не завершает приложение: история пишется дальше.

⌘R — обновить текущий раздел.

## Откуда данные

- IOKit: `AppleSmartBattery` (IORegistry) и IOPowerSources (`IOPSCopyPowerSourcesInfo`,
  `IOPSCopyExternalPowerAdapterDetails`), плюс уведомление о смене источника питания.
  На Apple silicon `MaxCapacity`/`CurrentCapacity` — проценты, ёмкость в мА·ч берётся из
  `NominalChargeCapacity` (иначе `AppleRawMaxCapacity`); на Intel — мА·ч прямо в `MaxCapacity`.
- `top -l 2 -s 1 -stats pid,command,power -o power -n 20` — второй замер; имя у `top` обрезано до 16 символов,
  поэтому настоящее имя и иконка берутся по PID (`proc_pidpath`).
- `ioreg -r -k BatteryPercent -a` (HID-устройства) и `system_profiler SPBluetoothDataType -json` (наушники,
  отключённые устройства). CoreBluetooth не используется — он вызвал бы запрос разрешения Bluetooth.

## История

Раз в минуту, пока BatteryMom запущен (в том числе только в строке меню), в
`~/Library/Application Support/BatteryMom/history.jsonl` дописывается строка:
`{"t": время, "p": %, "c": заряжается, "a": адаптер, "w": Вт Mac, "bw": Вт батареи, "tc": °C, "cyc": циклы}`.
Записи старше 30 дней удаляются (при запуске и раз в 6 часов). Чтобы минутный таймер не растягивался
App Nap'ом при закрытом окне, приложение держит фоновую активность (сон Mac не запрещает).

## Сборка и проверка

```sh
./Scripts/build_app.sh                 # build/BatteryMom.app (иконка — Resources/AppIcon.png)
swift run BatteryMom --status          # батарея, устройства и история в консоль, без окна
swift run BatteryMom --energy          # топ приложений по энергопотреблению
swift run BatteryMom --selftest        # разборщики на заготовленных выводах, история во временной папке
open build/BatteryMom.app --args --section devices   # раздел при запуске (battery|history|energy|devices)
open build/BatteryMom.app --args --no-battery        # интерфейс так, как его видит Mac без батареи
```

## Устройство

```
Sources/BatteryMom/
  BatteryMomApp.swift   точка входа, окно, меню, значок в строке меню, аргументы запуска
  AppState.swift        состояние: батарея, устройства, расход, таймеры записи истории
  CLI.swift             --status, --energy, --selftest
  Model/
    Battery.swift       чтение и разбор AppleSmartBattery + IOPowerSources
    Devices.swift       разбор ioreg и system_profiler, объединение
    Energy.swift        разбор top, группировка helper-процессов по приложениям
    History.swift       history.jsonl: запись, чтение, обрезка; точки графиков и итоги дней
    Fixtures.swift      заготовленные выводы утилит для --selftest
    Core.swift          формат, запуск команд, ссылки на Системные настройки
  Views/                экраны и общие компоненты (fillAvailable — см. комментарий в Components.swift)
```

## Ограничения

- Дата изготовления батареи на Apple silicon хранится в незадокументированном виде — не показывается.
- «Энергопотребление» — относительная оценка macOS, а не ватты; сумма по приложениям не равна потреблению Mac.
- Заряд iPhone/iPad и устройств, которые не сообщают его macOS, не виден.
