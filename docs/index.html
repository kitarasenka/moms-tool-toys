Mom's Tool Toys

Семь маленьких приложений для домашнего Mac и одно окно, чтобы их запускать. Wi-Fi, производительность, уборка, диски, приватность, батарея и буфер обмена — понятно и без лишнего.

Как установить

Приложения собираются из исходников на вашем Mac — это пара минут.

1. Инструменты AppleНужны Command Line Tools: xcode-select --install. Для WifiMom ещё Node.js.
2. Скачать и собратьОдин скрипт собирает всё и кладёт в «Программы».
3. ЗапуститьОткройте «Mom's Tool Toys» через Spotlight или Launchpad — дальше всё оттуда.
# скачать git clone https://github.com/kitarasenka/moms-tool-toys.git cd moms-tool-toys # собрать и установить всё в /Applications ./install.sh # запустить open -a "Mom's Tool Toys"
